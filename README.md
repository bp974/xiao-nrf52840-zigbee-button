# XIAO nRF52840 Zigbee Button Starter

Starter scaffold for a battery-powered Zigbee button using:

- Seeed Studio XIAO nRF52840 (non-Sense is fine)
- nRF Connect SDK 2.9.3
- Nordic's built-in `nrf/samples/zigbee/light_switch`
- Zephyr board: `xiao_ble`

The project intentionally bootstraps from the Nordic sample already installed on your machine instead of vendoring a copy of Nordic's source.

## First goal

Do not optimize power or rewrite the application yet.

The first milestone is:

1. Build the stock Nordic Zigbee light switch for `xiao_ble`.
2. Flash it by UF2.
3. Join it to Zigbee2MQTT.
4. Verify a physical button generates Zigbee behavior.
5. Verify the device can use Nordic's Sleepy End Device mode.

Only after that works should we simplify the app into the final two-button remote.

## Wiring

Buttons connect between the XIAO pin and GND. The devicetree enables internal pull-ups.

| Function | XIAO pin | nRF52840 GPIO | Nordic sample role |
|---|---|---:|---|
| Button 1 | D1 | P0.03 | ON / increase |
| Button 2 | D2 | P0.28 | OFF / decrease |
| Button 3 | D3 | P0.29 | Enable sleepy mode during first join |
| Button 4 | D4 | P0.04 | Factory reset / identify |

For the first test you only need Button 1. Unwired buttons remain HIGH because of their internal pull-ups.

## Setup

Open an nRF Connect SDK 2.9.3 terminal in VS Code, or otherwise make sure the 2.9.3 toolchain is active.

Then:

```bash
cd xiao-nrf52840-zigbee-button-starter
./scripts/bootstrap.sh
./scripts/build.sh
```

The bootstrap script searches common NCS 2.9.3 locations, or you can specify yours:

```bash
NCS_ROOT=/opt/nordic/ncs/v2.9.3 ./scripts/bootstrap.sh
```

The build output should be under:

```text
build/zephyr/
```

## Flash

Put the XIAO into its UF2 bootloader and find the mounted volume:

```bash
ls /Volumes
```

Then copy:

```bash
cp build/zephyr/zephyr.uf2 /Volumes/XIAO-SENSE/
```

The volume label can vary. Use the actual mounted UF2 volume name.

## Sleepy End Device test

The stock Nordic light-switch sample enables sleepy behavior when Button 3 is held while the device joins for the first time.

For this scaffold:

- Button 3 = XIAO D3 to GND.
- Hold it during first commissioning.
- Once this is proven, the final project can enable sleepy behavior automatically instead of requiring the boot gesture.

## Why four buttons for a two-button project?

The Nordic sample assumes the DK-style four-button interface. Keeping all four logical inputs lets us test the official application with minimal source changes.

Once basic Zigbee operation is proven, the intended final application is:

- D1 = Button A
- D2 = Button B
- single / double / long press actions
- automatic sleepy end-device configuration
- battery reporting
- no dependency on DK semantics
- aggressive low-power tuning

See `docs/NEXT_STEPS.md`.


## Notes

- This starter does not modify `/opt/nordic/...`.
- `app/` is generated by `bootstrap.sh` and intentionally excluded from git.
- The XIAO Zephyr board already supplies the nRF52840 radio/IEEE 802.15.4 configuration and UF2-oriented flash layout.
